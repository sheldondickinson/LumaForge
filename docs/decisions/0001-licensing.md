# ADR 0001: Licensing remains undecided

- Status: Accepted
- Date: 26/07/2026

## Context

The repository is public, but the owner has not selected or approved a licence.

## Decision

No `LICENSE` file will be created during bootstrap. The README states: “Licence: All rights reserved until a licence is selected.”

## Consequences

No open-source permissions are granted. A future licence requires explicit repository-owner approval and a superseding decision record.
