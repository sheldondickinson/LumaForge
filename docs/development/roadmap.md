# Roadmap

Delivery proceeds through reviewed milestones:

1. Repository bootstrap and minimal application proof.
2. Application foundation, local administrator authentication, and audit plumbing.
3. Product definitions, revisions, physical assets, and permanent identifiers.
4. Hierarchical locations, movement history, stocktake, QR, and Code 128 labels.
5. Typed effective-dated relationships, assemblies, elements, and positions.
6. Controllers, power, outputs, allocations, and structured logical identifiers.
7. Electrical and compatibility validation with documented overrides.
8. Verified NAS deployment, backup, restore, and rollback.
9. Versioned, read-only xLights import and reconciliation.

The current milestone implements item 4 as a stacked change on the product and
asset foundation. Relationship, controller, electrical, deployment and xLights
modules remain separate reviewed changes.
